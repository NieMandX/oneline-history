# Main History

Интерактивный исторический атлас: 20 полных столетий с 1 по 2000 год и 26 лет XXI века. Первая редакционная подборка содержит 47 событий мировой истории.

## Запуск

Нужен только Python 3 — сборки и установки зависимостей нет:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Открыть http://127.0.0.1:4173. ES-модулям нужен HTTP-сервер: открытие index.html через file:// не поддерживается. Для размещения достаточно отдать файлы проекта любым статическим HTTP-хостингом. Относительные пути позволяют размещение в подкаталоге.

## Возможности

- Непрерывная пропорциональная шкала; век начинается с года `100n + 1`. Правый край — исключительная граница 2027, поэтому 2001–2026 занимает 26/100 века.
- Приближение кнопками, выбором масштаба, Ctrl/⌘ + колесом; перемещение перетаскиванием и горизонтальной прокруткой. Поддержка Pointer Events для сенсорного ввода.
- Клавиатура при фокусе на шкале: ← →, + / −, Home, End, 0 для сброса.
- Переход к столетию, темы событий, разворачивание групп плотных событий.
- Карточки с последствиями, регионом и ссылкой на источник; список всех событий с поиском.
- Прямые ссылки на события: `/#printing`, `/#moon`, `/#web`.
- Мобильная вёрстка, видимый фокус, семантические кнопки, уменьшение анимации при `prefers-reduced-motion`.

## Архитектура и производительность

Vanilla HTML/CSS/JavaScript, без зависимостей, изображений, внешних шрифтов и сторонних сетевых запросов при загрузке. Изображение дизайн-концепции не входит в приложение. Системный гротеск и Georgia доступны без загрузки.

`events.js` — редактируемые данные; `timeline.js` — чистая календарная математика и размещение подписей; `app.js` — состояние и взаимодействия; `styles.css` — дизайн и адаптивность. Перерисовки объединяются через requestAnimationFrame и затрагивают только шкалу. Непрерывного анимационного цикла нет; на общем плане второстепенные события объединяются в группы. Полный список остаётся доступен независимо от масштаба.

## Историческая редактура

Это отправная подборка, а не объективный рейтинг важности. Отбор учитывает длительность последствий, масштаб влияния и изменения знаний, институтов и повседневной жизни. География включает Азию, Африку, Европу, Америки и Океанию; баланс и полнота требуют дальнейшей редакторской работы.

Точки процессов обозначают их начало; интервалы и приблизительность сохраняются в данных и подробной карточке. Нет утверждения, что книгопечатание впервые появилось в Европе, веб совпадает с изобретением интернета или все перемены происходили в один день. Ссылки — материалы для проверки и дальнейшего чтения, а не знак полной академической рецензии. Для ряда событий используется Wikipedia; профильные материалы APHA, NASA, CERN, ВОЗ, ООН, NHGRI и Nobel Prize — там, где они непосредственно относятся к теме. Не все ссылки прошли отдельную ручную проверку содержимого.

Срез: 3 ноября 2026. Добавление новых эпох потребует расширить границы в `timeline.js`; текущая модель не включает даты до н. э. Их следует вводить с отдельным календарным преобразованием, без фиктивного года ноль.

## Проверки

При наличии Node.js 20+:

```sh
node --test timeline.test.mjs
```

Проверяются границы веков, частичный XXI век, ограничения перемещения, сохранение точки при зуме, отсутствие пересечений подписей на разных ширинах, целостность данных и ссылок. Зависимости для тестов не нужны.

Дизайн: белый, чёрный и красный; правила описаны в DESIGN.md. Первый прототип следует проверять на реальных маломощных телефонах перед обещанием конкретной частоты кадров.
